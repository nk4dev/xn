---
title: コントリビュート
description: ベータ版の XN に不具合の報告や改善の提案を送る方法。
---

XN はベータ版です。コマンド、設定、チェックポイントの形式は、バージョンによって変わることがあります。

Issue を歓迎しています。動かないところ、分かりにくい説明、アイデアがあれば、[GitHub Issues](https://github.com/nk4dev/xn/issues) で Issue を立ててください。

不具合を報告するときは、次の情報があると調べやすくなります。

- 実行したコマンドとその出力
- `xn doctor` の出力
- OS と、CPU、CUDA、MPS のどれで学習しているか
