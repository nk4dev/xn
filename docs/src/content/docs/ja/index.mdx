## インストール

```sh
curl -fsSL https://apps.nknighta.me/xn/install.sh | sh
```

[uv](https://docs.astral.sh/uv/) と [Rust](https://rustup.rs/) が必要です。`sh -s -- --install-deps` を付けると、足りないものをスクリプトがインストールします。詳しくは[はじめる](getting-started/)を参照してください。

## 最初のモデルを作る

```sh
xn init myllm && cd myllm
xn train
xn generate --prompt "To be"
```
