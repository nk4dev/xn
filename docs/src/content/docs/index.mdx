## Install

```sh
curl -fsSL https://apps.nknighta.me/xn/install.sh | sh
```

You need [uv](https://docs.astral.sh/uv/) and [Rust](https://rustup.rs/). Add `sh -s -- --install-deps` to have the script install them for you. See [Getting started](getting-started/) for details.

## Train your first model

```sh
xn init myllm && cd myllm
xn train
xn generate --prompt "To be"
```
