## `xn`

| Variable | Description |
|---|---|
| `XN_ENGINE` | Path to the engine (the directory containing `pyproject.toml`). Default: the source `xn` was built from. Set it if you move that directory. |
| `XN_UV` | uv executable to use. Default: `uv` on `PATH`. |
| `XN_TORCH` | PyTorch build: `auto` (default; `cuda` if `nvidia-smi` works, else `cpu`), `cpu` or `cuda` (CUDA 12.6). |

## `install.sh`

| Variable | Description |
|---|---|
| `XN_REPO` | Git URL to clone when the script is not run from a checkout. Default: `https://github.com/nk4dev/xn.git`. |
| `XN_HOME` | Where to clone. Default: `~/.local/share/xn`. |
